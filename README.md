# Rawell Química — Catálogo de Produtos 2026

Catálogo digital interativo e Progressive Web App (PWA) de produtos da Rawell Química (defensivos, fungicidas, inseticidas, raticidas e soluções para jardinagem e saúde pública).

## 🚀 Funcionalidades
- **Catálogo Interativo**: Listagem de produtos, filtros por categorias e páginas de detalhes.
- **PWA (Progressive Web App)**: Suporte a instalação no celular e funcionamento offline via Service Worker (`sw.js`).
- **Orçamento via WhatsApp**: Integração para montagem de pedidos e envio direto para atendimento.
- **Catálogo em PDF**: Disponibilização do catálogo completo para download.

## 🌐 Deploy
Configurado como **Static Site** pronto para publicação no [Render](https://render.com) ou GitHub Pages.

- **Publish Directory**: `.`
- **Página principal**: `index.html`
